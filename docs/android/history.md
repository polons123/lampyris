# Android: история версий 0.1.x

До объединения нумерации с macOS и Windows (с 1.1.0 версия общая, `scripts/VERSION`).

## Исправления 0.1.1

Оболочка корректно распознаётся Lampa: устранена блокировка торрент-файлов с предупреждением о MediaStationX. Торренты идут через настроенный TorrServer во встроенный mpv; исправлены player_torrent и internal_torrclient. Протокол запросов Android совместим со стандартными AJAX-запросами WebView, сохраняющими CORS и маршрутизацию приложения. Нативный HTTP-мост не добавлен. AndroidJS — объект JavaScript, внедрённый до запуска страницы через AndroidX WebKit только на выбранном сервере и в главном кадре. Меню находится в левом нижнем углу и скрывается при воспроизведении. Раздельное исключение mpv из VPN отложено по просьбе пользователя.

## Исправление 0.1.2

Устранено сообщение «Обновите приложение до версии 28» при изменении истории и избранного. Это проверка номера совместимости Android-клиента Lampa для обновления каналов Android TV. Планшетный адаптер принимает такой вызов без создания ТВ-каналов. Голосовой ввод предлагается выполнять через экранную клавиатуру.

### 0.1.3
В Android для онлайн-видео, IPTV и торрентов доступен только встроенный MPV. Сохранённый выбор внешнего плеера сбрасывается при запуске. Скрыты настройки запуска Infuse и пути к настольному плееру. Код Lampa на сервере не изменяется.

### 0.1.4
Исправлено повторное подключение плеера при навигации внутри Lampa: повторный onPageFinished больше не заменяет канал, который использует уже установленный MPV-адаптер. При загрузке нового документа создаётся новый канал с новой проверкой источника.

## Возможности 0.1.5

- Субтитры из интернета: кнопка субтитров на панели видео → русские или английские; поиск через OpenSubtitles/Stremio, скачивание выбранного файла и подключение к mpv. В «Настройки → MPV» есть ручной и автоматический режимы.
- TheIntroDB: «Настройки → MPV → Пропуск заставок» — выключено, кнопка или автоматически. В автоматическом режиме пропускаются заставка и пересказ; титры предлагаются кнопкой. Таймкоды доступны не для всех видео и могут отличаться между изданиями.
- Редактор mpv.conf: «Настройки → MPV → Конфигурация mpv». Общие параметры до первого раздела, профили в `[имя]`, `[default]` возвращает общие параметры. До 64 КиБ. Профиль с именем встроенного заменяет его. Проверенные диапазоны и значения заданы в PlayerConfig.java; неподдерживаемые строки показываются при сохранении. Применение со следующего видео; профиль можно выбрать во время просмотра.
- Перемотка: все четыре кнопки добавляются отдельно, касания обрабатываются напрямую. Последнее изменение позиции доставляется и на паузе. Шаг задаётся в «Настройки → MPV».
- Вертикальные свайпы во время видео: справа громкость устройства, слева яркость окна приложения, с индикатором уровня. Центральная часть и кнопки интерфейса не перехватываются. Системная яркость не изменяется.

Сетевые запросы новых функций ограничены сервисами субтитров и TheIntroDB, выполняются без cookie Lampa. Произвольный HTTP-мост не добавлен; маршрутизация через VPN не менялась.

## 0.1.6 — дорожки, информация и картинка

Кнопки I (информация) и V (картинка) находятся на панели плеера. I показывает сведения о файле как в macOS; повторное нажатие I или касание самого окна закрывает информацию. V открывает гамму, яркость, контраст, насыщенность, переключатель автокоррекции SDR, её отдельные гамму/насыщенность и сброс. Есть кнопка ×. Клавиши I/V работают с подключённой клавиатурой, C оставлена как дополнительная клавиша картинки.

Названия звуковых дорожек и субтитров строятся по фактическому списку mpv, а не по несовпадающему списку серверного парсера. Показываются язык, название озвучки, кодек/каналы; для субтитров — форсированные, полные, SDH, внешние/графические при наличии. Неизвестное название студии не угадывается. Пример: «Русский · LostFilm · AC3 2.0». Все дорожки доступны для выбора.

Исправлен контраст кнопки «Онлайн» в фокусе, переключатель SDR выровнен по центру строки и столбца ползунков; кружок центрируется по высоте независимо от размера шрифта.

## 0.1.7 — меню и сохранение дорожек, шрифт, скорость сети

Выбор звуковой дорожки расположен непосредственно слева от субтитров. В меню субтитров добавлены поиск в интернете и настройки размера, положения, цвета, фона и автоматического поиска. Изменения внешнего вида сразу применяются к текущему видео; отдельная кнопка интернет-субтитров убрана.

Явный выбор дорожек сохраняется для сериала. При следующей серии выбирается совпадение языка и названия озвучки, а не прежний номер дорожки. Для субтитров учитываются полные/форсированные/SDH; отключение также запоминается. Автоматические действия Lampa больше не перезаписывают этот выбор. Для выбранных внешних RU/EN-субтитров новая серия ищется отдельно — файл предыдущей серии не используется.

Настроен fontconfig до создания mpv: системные Roboto/Noto Sans для sans-serif/Arial/Helvetica вместо случайного служебного шрифта. Это исправляет отображение пробелов и букв на Xiaomi. Шрифты не скачиваются.

В информации I скорость чтения сети берётся из отдельного свойства mpv cache-speed, с обновлением раз в секунду. Нулевая скорость при заполненном буфере отмечается отдельно. Скорость скачивания торрента и скорость чтения потока — разные значения.

## Исправления после ревью — 0.1.8

Исправлены выход из теста по «Назад», освобождение/возврат аудиофокуса, остановка сервиса через внутренний shutdown, сброс ночного фильтра и раннее сохранение исходных настроек. При смене серии загрузка субтитров получает отмену. Пока Surface отсутствует, видеодорожка отключается; звук продолжает играть. Возврат восстанавливает выбранную видеодорожку. Расширен набор обрабатываемых изменений размеров/плотности экрана; восстановление после уничтожения процесса не реализовано.

Уведомления обновляют позицию по изменениям состояния и перемоткам, метаданные — при изменении. Список дорожек кэшируется до события его изменения. JS-ассеты кэшируются; тестовое видео копируется по требованию. WakeLock ограничен таймаутом и продлевается только при воспроизведении. Для публичных сервисов субтитров/таймкодов заблокированы CGNAT и IPv4-mapped приватные адреса. Валидация свойств моста использует диапазоны конфигурации.
