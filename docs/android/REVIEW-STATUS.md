# Результат разбора CODEX-REVIEW.md — 0.1.8

Оригинальный CODEX-REVIEW.md сохранён. Сборка отладочная, versionCode 9.

## Исправлено

- Пересоздание при изменении размеров: добавлены smallestScreenSize/screenLayout/density. Это не восстановление после уничтожения процесса, смены языка и любых возможных конфигураций. Реальное складное устройство не проверялось.
- PlaybackService всегда сначала выполняет startForeground, включая пустой/отменённый запуск; остановка через собственное действие shutdown и stopSelf. WakeLock ограничен 10 минутами с продлением каждые 5 минут только при воспроизведении.
- Тестовое видео закрывается единым closeTest как кнопкой, так и Back; интерфейс восстанавливается.
- Аудиофокус запрашивается после проверки параметров и подготовки профиля. Временная потеря ставит паузу с флагом, возврат возобновляет только её. Ручная пауза/остановка сбрасывает флаг; ручное воспроизведение вновь запрашивает фокус. CAN_DUCK не ставит принудительную паузу (Android автоматически приглушает MEDIA).
- При потере Surface отключается видеодорожка; при возврате восстанавливается выбранная дорожка. Аудио продолжает играть.
- Значения профилей сняты после MPVLib.init; af сбрасывается явной пустой строкой.
- Запрос загрузки субтитров при смене воспроизведения сразу получает ошибку отмены, если документ ещё тот же.
- Метаданные MediaSession обновляются при изменении, позиция — на pause/duration/speed/playback restart и заметном скачке времени, без ежесекундной пересборки.
- Список дорожек кэшируется до изменения, открытия/остановки файла. Структурированный JNI MPV_FORMAT_NODE не добавлялся.
- JS кэшируется в памяти. CA-файл копируется при смене версии, sample — по требованию. Ошибка подготовки файлов показывается диалогом.
- Добавлен OnBackInvokedCallback на Android 13+, WebView удаляется из контейнера перед destroy, типизированное чтение MediaSession.Token на Android 13+.
- Значения set проверяются диапазонами PlayerConfig; отдельно проверяются переключатели и ID дорожек.
- Числа конфигурации используют десятичный синтаксис; hex-float, NaN, Infinity отклоняются. Проверки кавычек, no-флагов, повторных секций, default, пустых значений подключены к Gradle check.
- Блокируются CGNAT и IPv4-mapped приватные адреса; автономные проверки адресов подключены к Gradle check.
- Добавлены ARM32 и универсальный APK, ТВ-ярлык, баннер, автоматический/ручной режим пульта, Info/Menu, передача стрелок вверх/вниз Lampa на ТВ.

## Уточнения и оставшаяся работа

- POST_NOTIFICATIONS не требуется для уведомления с MediaSession; запрос не добавлялся.
- WifiLock не добавлялся без подтверждённой проблемы Wi-Fi во сне. Длительное фоновое воспроизведение остаётся отдельной проверкой.
- Замена track-list на getPropertyString не гарантирует JSON. Пока применяется кэш; полноценная структурированная выдача требует пересборки JNI двух ABI.
- Главный экран ещё требует дальнейшего разделения на контроллеры и форматирования. Полный рефакторинг не смешивался с проверенными исправлениями поведения.
- Проверки конфигурации интегрированы в Gradle, но сохранены автономными Java-тестами, без JUnit/новых зависимостей.
- targetSdk остаётся 35; миграция 36 и замена старого управления системными панелями отдельно. Новый Back уже подключён.
- Release-подпись, R8/minify и изменение упаковки .so не включались. APK подписаны существующим debug-ключом.
- HTTP разрешён для произвольных пользовательских LAN-адресов; глобальное разрешение сохранено. DNS TOCTOU у HttpURLConnection не устранён. CA bundle нужно обновлять при релизах; произвольные частные CA не поддерживаются.
- ARM32-библиотеки взяты из официального upstream-релиза, не пересобраны локально. ARM64 оставлен прежним; наборы могут отличаться версиями зависимостей.
- Ugoos X4Q ещё не подключён: нужны реальные проверки пульта, декодеров, HDR и длительного просмотра.
