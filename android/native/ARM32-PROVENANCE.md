# ARM32 native libraries

Взяты без изменений из официального релиза mpv-android `2026-09-17`:
https://github.com/mpv-android/mpv-android/releases/tag/2026-09-17

APK: `app-default-armeabi-v7a-release.apk`
SHA-256: `30c63f5528530f56cdece5d6466c749976f01bdcd8c8e67ae76e70a54b7243aa`

Извлечены только `lib/armeabi-v7a/*.so`. Это готовые upstream-библиотеки; локальная перекомпиляция mpv/FFmpeg не выполнялась. JNI и скрипты из тега сохранены в `arm32-upstream/`; они содержат ссылки на исходники зависимостей. Контрольные суммы всех включённых .so находятся в `SHA256SUMS.txt`. Проверены ELF32 ARM, зависимости DT_NEEDED и запуск/декодирование на Android 15 с принудительной установкой ARM32. Ugoos X4Q пока не подключён и не проверен.

ARM64 сохранён из предыдущей проверенной локальной сборки. Бинарные наборы двух ABI могут использовать разные версии зависимостей; функциональные проверки обеих архитектур описаны в CHECKS.md.
