# Lampyris для Android (Preview)

Прототип для планшетов, телефонов и ТВ-приставок ARM32 / ARM64, Android 8.0 и новее. Проверен на подключённом Redmi (2307BRPDCC). Телефон отдельно не проверялся.

## Работающие возможности

- Открытие своего сервера Lampa/Lampac по HTTP(S), сохранение адреса и данных входа в приватном хранилище WebView.
- Встроенный mpv под прозрачным интерфейсом Lampa: переключения во внешний плеер нет.
- Аппаратное декодирование через MediaCodec, пауза, перемотка, продолжение с позиции, список дорожек.
- Семь встроенных профилей изображения из Lampyris, панель настройки картинки, автокоррекция SDR из общего скрипта.
- Меню ☰: смена сервера, перезагрузка, автономный тест плеера, язык приложения (русский/английский).

Установите APK, откройте Lampyris и введите адрес сервера. При необходимости пройдите вход на странице сервера. Адрес и пароль не вшиты в приложение.


## Сборка

Нужны JDK 17 и Android SDK с платформой 35. В `local.properties` укажите `sdk.dir=...` либо задайте `ANDROID_HOME`.

```sh
./gradlew :app:assembleDebug :app:lintDebug :app:playerConfigTest :app:networkAddressPolicyTest
```

APK в `app/build/outputs/apk/debug/`: `app-armeabi-v7a-debug.apk` (ARM32), `app-arm64-v8a-debug.apk` (ARM64), `app-universal-debug.apk` (обе ARM-архитектуры). Это отладочные сборки; универсальная не включает x86/x86_64.

Нативные библиотеки в git не хранятся: перед первой сборкой выполните `scripts/fetch-libs.sh` (скачивает и проверяет их). Обе архитектуры взяты без изменений из официального релиза mpv-android 2026-09-17; происхождение и суммы — `native/ARM32-PROVENANCE.md`, `native/libs.lock`, `native/SHA256SUMS.txt`. JNI-код и скрипты сборки upstream лежат в `native/`; для пересборки см. `native/buildscripts/README.md` (Linux, NDK и исходники зависимостей). Эти скрипты сами по себе не гарантируют побитное воспроизведение включённых бинарных файлов: некоторые upstream-ревизии в них не закреплены.

## Устройство

`MainActivity.java` содержит Android-оболочку, SurfaceView, WebView, управление аудиофокусом и ограниченный мост mpv. `MPVLib.java` сохраняет сигнатуры существующего JNI. `mpvTube.js` и `playbackCover.js` взяты из Lampyris; Android-копия скрывает недоступные функции и ограничивает буфер 128 МиБ. `tablet.js` добавляет размеры сенсорных элементов.

Мост использует WebMessagePort с точным адресом основного документа, одноразовым случайным идентификатором соединения и проверкой Android-сообщения (`source=null`, пустой `origin`). Переход на другой сервер требует подтверждения. Команды страницы ограничены перемоткой; произвольные команды mpv и запуск программ отклоняются. Файловый доступ WebView отключён. TLS-проверка включена; тестовое видео сгенерировано локально.

## Текущие ограничения

Перенос резервной копии с ПК, скриншоты средствами плеера, PiP и автообновления пока не перенесены. Редактор поддерживает ограниченный набор параметров картинки, звука и субтитров; произвольные фильтры, пути, команды и сетевые параметры недоступны. Длительный просмотр, HDR/Dolby Vision и телефонный интерфейс требуют отдельного тестирования.

## Проверка на телевизоре / Ugoos X4Q

Установите ARM32 APK, если система сообщает `armeabi-v7a`, либо универсальный APK. Добавлен запуск через Leanback и баннер. В меню ☰ можно выбрать «Управление: планшет / телевизор» → «Телевизор / пульт», если прошивка не определяется как ТВ автоматически. Кнопка Menu пульта открывает меню оболочки. Стрелки вверх/вниз на видео передаются панели Lampa, влево/вправо перематывают; в меню стрелки работают штатно. Кнопка Info пульта, если она есть, открывает информацию о файле. I и V доступны на панели плеера. Кнопка «Назад» сначала закрывает открытое меню дорожек/картинки.

На Ugoos ещё нужны проверки пульта, кодеков, HDR, длинного воспроизведения и сна. Не считать наличие ТВ-ярлыка завершённой сертификацией Android TV.


## Сеть и сертификаты

- HTTP (без TLS) разрешён для всего приложения: сервер Lampa/Lampac обычно стоит в локальной сети на произвольном адресе, и перечислить их заранее нельзя. Внешние сервисы (субтитры, TheIntroDB) работают только по HTTPS на фиксированных хостах, с запретом приватных адресов (включая NAT64, 6to4 и IPv4-совместимые IPv6) и без cookie Lampa.
- `cacert.pem` — пакет корневых сертификатов Mozilla от curl.se (контрольная сумма сверяется с `cacert.pem.sha256` на сайте). Перед каждым релизом обновляйте файл; `./gradlew check` предупреждает, если пакет старше 180 дней.
- Во время воспроизведения удерживается блокировка Wi-Fi (только пока идёт видео и не на паузе), чтобы сетевой поток не прерывался при погашенном экране.
