# Lampyris

**Русский** | [English](README.en.md)

Неофициальный клиент [Lampa](https://github.com/yumata/lampa) для macOS (Apple Silicon и Intel) и Windows (x64 и arm64); версия для Android (планшеты, телефоны, ТВ-приставки, ARM32/ARM64; сейчас Preview): [android/README.md](android/README.md). Lampa — проект своих авторов, Lampyris с ним не связан и не поддерживается им. На macOS приложение написано на Swift/AppKit с WKWebView, на Windows на Rust с WebView2; воспроизведение везде через libmpv.

## Почему Lampyris
- **Настоящий плеер mpv вместо плеера в браузере.** Аппаратное декодирование (VideoToolbox на macOS, D3D11VA на Windows), AC3/DTS и 4K/HDR без перекодирования и без «тормозов» веб-плеера.
- **Качество картинки под вашу задачу.** Семь встроенных профилей (`balanced`, `quality`, `fast`, `hdr-sdr`, `smooth`, `anime`, `night`) с описаниями в окне выбора: переключаются во время просмотра клавишей `P` и запоминаются. Свои профили добавляются в `mpv.conf` и перекрывают встроенные.
- **Панель «Картинка» (клавиша `C`).** Ползунки гаммы, яркости, контраста и насыщенности для ручной подстройки (например, тёмного видео) и «Автокоррекция SDR»: подтягивает тени и цвет только у SDR-видео, HDR не трогает.
- **Свой `mpv.conf` с редактором и защитой.** Опции, запускающие код или читающие чужие файлы, отключены; профили выбираются из настроек.
- **Одинаковые возможности на macOS и Windows.** Общие страницы и мост для обеих платформ. Для Windows есть установщик, обычный портативный `.zip` и полностью портативная сборка (всё в папке рядом с exe).
- **Безопасные обновления.** Автопроверка, подпись Ed25519, проверка контрольной суммы; настройки и вход в Lampa при обновлении сохраняются.
- **Резервная копия настроек** одним файлом, общим для macOS и Windows.
- **Русский и английский интерфейс**, язык переключается в меню.

## Возможности
- Продолжение просмотра, запоминание озвучки и субтитров по сериалу, автоповтор при обрыве сети.
- Пропуск заставок и титров по таймкодам TheIntroDB, субтитры из интернета (русские и английские).
- Дорожки: подписи «язык · студия · кодек каналы» и типы субтитров, память выбора для сериала, клавиши `A` и `J`, порядок предпочтений и умный выбор субтитров в «MPV». Вид субтитров (`Y`, с примером поверх видео), главы (`PgUp` `PgDn`).
- Звук (`E`): эквалайзер на 10 полос с пресетами, усиление речи и ночной режим. Таймер сна (`T`), необязательный вопрос «Вы ещё смотрите?» после трёх серий подряд без нажатий.
- Пропуск по главам файла («Opening», «Титры» и т. п.), если в TheIntroDB нет таймкодов. Пресеты в панели «Картинка».
- Локальные файлы: «Файл → Открыть видео…» (⌘O / Ctrl+O), перетаскивание в окно, «Открыть с помощью»; на Android кнопка в «Настройки → MPV». Несколько файлов становятся плейлистом, работают все функции плеера.
- Частота экрана под видео (в «Настройки → MPV», выключено по умолчанию): 24 к/с на 24 или 48 Гц и т. п., только в полноэкранном режиме.
- Клавиши плеера (справка по `H`), статистика (`I`), скриншот (`S`), медиаклавиши и «Сейчас играет».
- Запоминание окна, меню приложения, страница ошибки, журнал.
- Язык приложения меняется в меню: macOS — меню Lampyris → «Язык / Language», Windows — «Настройки → Язык / Language»; пока выбор не сделан, берётся язык системы. Подсказки плеера внутри Lampa следуют языку самой Lampa (Настройки → Интерфейс). Установщик для Windows тоже двуязычный (по языку Windows).
- На Windows полный экран (`F11`), медиаклавиши и «Сейчас играет» через системные элементы Windows.

## Установка
Две сборки (обе требуют macOS 13 или новее): `Lampyris-<версия>-arm64` для Mac с Apple Silicon и `Lampyris-<версия>-intel` для Mac с процессором Intel. Откройте .dmg и перетащите Lampyris в «Программы».

Сборка подписана ad-hoc (без сертификата разработчика Apple), поэтому при первом запуске macOS может написать, что не может проверить приложение. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть», либо выполните в Терминале `xattr -dr com.apple.quarantine /Applications/Lampyris.app`.

### Android (Preview)
`Lampyris-<версия>-android-arm64.apk` (большинство современных устройств), `…-arm32.apk` (старые и ТВ-приставки с 32-битной системой) или `…-universal.apk` (обе архитектуры). Android 8.0 и новее. Установите APK вручную (разрешите установку из этого источника), откройте Lampyris и введите адрес сервера Lampa. Автообновления на Android пока нет. Подробности, ограничения и что не проверено: [android/README.md](android/README.md).

### Windows
Установщик `Lampyris-<версия>-windows-x64-setup.exe` или `-arm64-setup.exe` (ставит для текущего пользователя без прав администратора, добавляет ярлык в меню «Пуск», удаляется через «Приложения») либо портативный `…-windows-<arch>.zip`: распакуйте в любую папку и запустите `Lampyris.exe` (нужен WebView2 Runtime, он есть в Windows 11 и в обновлённой Windows 10). Сборки не подписаны, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае». 

**Полностью портативный вариант** `…-windows-<arch>-portable.zip`: те же файлы плюс `portable.txt` и папка `data`. Настройки, адрес сервера, вход в Lampa, данные WebView2, журнал и `mpv.conf` лежат в `data` рядом с `Lampyris.exe`, а не в папках пользователя; папку можно целиком перенести или сохранить перед переустановкой Windows. Режим включается наличием `portable.txt` рядом с exe (удалите файл — вернётся обычное хранение); обновляется этот вариант своим архивом, `data` не затрагивается. Это дополнительный вариант, установщик и обычный `.zip` работают как прежде.

**Несколько экземпляров.** По умолчанию Lampyris можно запустить несколько раз. Запретить это можно в меню «Настройки → Запретить несколько экземпляров» (галочка включает запрет, повторный щелчок снимает; действует со следующего запуска): повторный запуск тогда лишь выводит вперёд уже открытое окно. Минимальный размер окна — 800×600.

Устройство приложения: [docs/ARCHITECTURE-windows.md](docs/ARCHITECTURE-windows.md).

```
cd windows && cargo test --release              # тесты (разбор mpv.conf, журнал, мост)
windows\scripts\build-windows.ps1 -Arch x64      # или arm64: пакет и .zip в dist\
windows\scripts\build-installer.ps1 -Arch x64    # установщик из этого пакета (нужен Inno Setup 6); подпись: LAMPYRIS_SIGN_PFX и LAMPYRIS_SIGN_PASSWORD
```
Нужны Rust (цели `x86_64-pc-windows-msvc` и `aarch64-pc-windows-msvc`) и Visual Studio Build Tools с C++; libmpv скачивается скриптом с проверкой SHA-256.

### Резервная копия настроек
Меню «Сохранить настройки в файл…» и «Восстановить настройки из файла…» (macOS: меню Lampyris; Windows: «Настройки») записывают и читают один файл `Lampyris-настройки-<дата>.json`: адрес сервера и история адресов, переключатели меню, `mpv.conf` и данные страницы Lampa (вход, закладки, плагины, настройки Lampa). Формат общий: копию с Mac можно восстановить на Windows и наоборот. Положение окна в копию не входит. Файл содержит адрес вашего сервера и данные входа, храните его как личный; восстановление заменяет текущие настройки после подтверждения и перезагружает страницу.

### Профили mpv и панель «Картинка»
Встроенные профили есть всегда: выберите «Настройки → MPV → Профиль mpv» или нажмите `P` во время видео. Описание профиля показано в окне выбора. Чтобы изменить встроенный профиль, добавьте в `mpv.conf` раздел с тем же именем: он целиком заменит встроенный.

Клавиша `C` открывает панель «Картинка»: четыре ручных ползунка (гамма, яркость, контраст, насыщенность — поправки поверх профиля) и «Автокоррекция SDR» со своими гаммой и насыщенностью. Значения запоминаются и ставятся при каждом открытии видео; «Сбросить всё» возвращает значения профиля. Итог считается как профиль + автокоррекция (только для SDR) + ручная поправка.

На macOS рендерер `gpu` (OpenGL 4.1): опции только для `gpu-next` не действуют, а `hdr-compute-peak` без compute-шейдеров ничего не делает. На Windows рендерер `gpu-next`, и они работают.

### Обновление
Приложение само проверяет обновления (при запуске, не чаще раза в сутки; вручную — «Проверить обновления…» в меню; автопроверку можно выключить) и предлагает установить новую версию: скачивает её с GitHub Releases, проверяет подпись и контрольную сумму и заменяет себя. Адрес сервера, настройки и вход в Lampa хранятся вне папки программы и при обновлении сохраняются.
- Windows: установленная копия обновляется установщиком (тихо, в ту же папку и в том же режиме), портативная — заменой файлов.
- macOS: заменяется `Lampyris.app`, прежняя версия неделю лежит в `~/Library/Caches/Lampyris/update`.
- Если автоустановка невозможна (например, приложение запущено прямо из загрузок), откроется страница релиза.

Сетевых обращений, кроме запросов к GitHub за версией и файлами, нет.

## Сборка .app
```
scripts/build-app.sh arm64      # Apple Silicon
scripts/build-app.sh x86_64     # Intel
```
Скрипт скачивает готовые библиотеки mpv IINA под нужную архитектуру и проверяет их контрольные суммы, собирает приложение, формирует `dist/<arch>/Lampyris.app`, проверяет состав (`scripts/verify-bundle.sh`), подписывает ad-hoc и упаковывает `.zip` и `.dmg` в `dist/`. Нужны Xcode или Command Line Tools со Swift 6; Homebrew и mpv для сборки `.app` не нужны.

## Запуск из исходников
```
brew install mpv        # библиотека для swift run; для сборки .app Homebrew не нужен
cd lampyris && swift run
```
Адрес сервера Lampa берётся из `LAMPA_URL`, затем из настроек, иначе будет спрошен. Устройство приложения, переменные отладки и ограничения — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Тесты и проверки
```
scripts/check.sh        # синтаксис shell-скриптов и внедряемого JS, запрет append с несколькими аргументами
swift test              # разбор mpv.conf и сокращение адресов в журнале (цель LampyrisCore)
```
`swift test` собирает весь пакет, поэтому библиотеки mpv должны быть доступны: либо Homebrew (`brew install mpv`), либо `LAMPA_LIBS=<каталог с dylib>` (например, после `scripts/fetch-libs.sh arm64`: `LAMPA_LIBS=$PWD/build/libs/arm64`).

## Непрерывная интеграция и выпуск версии
`.github/workflows/ci.yml` (GitHub Actions) на каждый пуш в `main` и на каждый запрос слияния:
1. запускает проверки и тесты на macOS (Apple Silicon);
2. собирает `Lampyris.app` под arm64 (Apple Silicon) и под x86_64 (настоящий Intel-раннер `macos-26-intel`), проверяет состав пакета и делает дымовой запуск (воспроизведение тестового видео);
3. сохраняет `.dmg` и `.zip` каждой сборки как артефакты запуска;
4. то же для Windows: `cargo test`, пакет x64 (и arm64 для публичного репозитория), дымовой запуск, `.zip` и установщик `-setup.exe` как артефакты.

Чтобы выпустить версию, поднимите номер в `scripts/VERSION`, закоммитьте и поставьте тег вида `v0.1.0`: CI соберёт обе сборки и опубликует релиз с `.dmg`, `.zip` и установщиками `-setup.exe` (Windows) , `SHA256SUMS.txt` и его подпись `SHA256SUMS.txt.sig` (ключ — секрет репозитория `UPDATE_SIGNING_KEY`; по ней приложения проверяют обновления). Для работы с файлами workflow через `gh` у токена должно быть право `workflow` (`gh auth refresh -h github.com -s workflow`).
