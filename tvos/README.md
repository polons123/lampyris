# Lampyris TV

Клиент Lampa и Lampac для Apple TV с tvOS 18 и новее. Видео можно смотреть во встроенном mpv или открывать в Infuse. Веб-интерфейс использует частный WebKit tvOS. Проект рассчитан на установку через Xcode.

## Запуск на другом Mac

Для первой загрузки выполните в Terminal

```sh
git clone --branch tvos-prototype https://github.com/polons123/lampyris.git
open lampyris/tvos/LampyrisTV.xcodeproj
```

В Xcode выберите схему **LampyrisTV**, дождитесь загрузки зависимостей Swift Package Manager, выберите симулятор **Apple TV 4K** и нажмите **Run**. Для установки на приставку откройте на ней **Настройки → Пульты и устройства → Удалённое приложение и устройства**, выполните сопряжение в **Window → Devices and Simulators** в Xcode и выберите свою команду в **Signing & Capabilities**.

При первом запуске открывается Lampa. В правом меню выберите **Адрес сервера Lampac**, введите свой URL и подтвердите. При необходимости войдите на сервер. В настройках плеера выберите **mpv** или **Infuse**. Для второго варианта установите Infuse на приставку.

## Встроенный mpv

- Позиция просмотра привязывается к фильму или серии. При наличии времени изменения плеер выбирает более свежую отметку Lampa или mpv, в том числе после перемотки назад.
- Плеер показывает список полученных эпизодов и по окончании серии открывает следующую. Для TorBox серверный плагин должен передавать список файлов сезона и предоставлять свежую ссылку на выбранный файл. В этом каталоге находится клиент tvOS.
- Для поддерживаемых потоков TorrServer в информации о файле отображаются скорость загрузки и число активных пиров.
- Метки источника, главы MKV и TheIntroDB используются для пропуска сегментов. Для размеченных вступлений и пересказов появляется соответствующая кнопка. На титрах можно перейти к следующей серии.

## Проверки

Из корня репозитория на Mac с Node.js и инструментами Xcode выполните

```sh
cat tvos/checks/tv-js-smoke.js tvos/Remote.js tvos/checks/tv-js-verify.js | node
check_dir=$(mktemp -d)
xcrun --sdk macosx clang -fobjc-arc -framework Foundation tvos/checks/tv-url-smoke.m -o "$check_dir/url-smoke" && "$check_dir/url-smoke"
```

На симуляторе проверены переход между сериями TorBox и отображение статистики TorrServer. После изменений в обработке прогресса и меток стоит повторить два сценария в интерфейсе. Откройте один фильм из онлайн-источника и торрента после перемотки назад и сравните позицию. Затем откройте серию с одними титрами и проверьте момент появления кнопки перехода.

На физической Apple TV осталось проверить управление пультом и фактический режим телевизора для SDR и HDR при включённой и выключенной **Подстройке частоты экрана под фильм**.
